# head_message 작성 기준

`head_message`는 발표 슬라이드의 **standalone 핵심 메시지**.
청중이 본문을 읽지 않아도, 헤드 한 줄만으로 그 슬라이드의 결론·함의를 가져갈
수 있어야 한다. "그래서 뭐?"가 따라붙으면 실패다.

이 가이드는 outline 작성 단계, slide_content LLM 호출, deterministic check,
self-review 모두가 인용하는 single source of truth이다.

---

## 핵심 원칙 — Standalone Meaningfulness

헤드만 떼어서 보여줬을 때 **반문이 들지 않아야 한다**.

| 분류 | 예 | 왜 |
|---|---|---|
| ❌ 라벨 (반문 발생) | "AI의 영향" | "어떤 영향?" 반문 |
| ❌ 토픽 포인터 (반문 발생) | "ChatGPT 1억 사용자 달성 사례" | "그래서 뭐? 그게 왜 중요?" 반문 |
| ❌ 의문형 | "AI는 어떻게 변화시키는가" | 발표 슬로건이지 결론 아님 |
| ❌ 다중 주제 | "직무와 산업의 재편과 변화" | 한 슬라이드 = 한 주제 |
| ✅ Standalone | "ChatGPT, 2개월 만에 1억 사용자 — 역대 최단" | 사실+함의가 명시 |
| ✅ Standalone | "Fortune 500의 92%가 이미 생성형 AI 도입" | 주체+수치+함의 명시 |
| ✅ Standalone | "노동 30% AI 대체 가능 — 핵심은 '재구성'" | 수치+함의 명시 |

## 5가지 작성 기준 (모두 통과 필수)

### 1. Standalone — "그래서 뭐?" 반문이 들지 않는다

헤드 안에 **[주체] + [구체적 사실/수치] + [함의]** 중 **최소 두 가지**가 있어야 한다.

- 주체: 누구·무엇에 대한 사실인가 (ChatGPT, Fortune 500, 법률업계)
- 사실/수치: 측정 가능한 사실 (2개월 1억 명, 92%, 5.2배)
- 함의: 청중이 가져갈 의미 (역대 최단, 도입 단계 → 운영, 격차 요인 부상)

```
"기업 도입률"             — 주체·수치·함의 모두 모호 ❌
"Fortune 500 92% 도입"   — 주체+수치 ✓ (함의는 약하지만 사실이 강해 OK) △
"Fortune 500의 92%가 이미 도입 — 운영 단계로 이동" — 셋 다 ✓ ✅
```

### 2. 한 줄 fit (글자 수 아닌 줄 수)

본문 영역 폭(12.13in) × 18pt 기준 한국어 ≈ 25~40자, 영문 ≈ 60~80자.
deterministic check가 line_count로 측정.
초과 시 자동 줄바꿈으로 시각 무게 분산 → reject.

### 3. 한 슬라이드 = 한 주제

`A와 B`, `A 그리고 B` 같은 묶음은 두 주제 신호. 의심하고 분리·재작성.

### 4. 의문형 절대 금지

`?`로 끝나거나 `~까/~가/~는가` 어미 → reject. 청중에게 답을 떠넘기지 않는다.

### 5. 종결형은 자유

명사구 (`Fortune 500 도입 현황`)도, 짧은 서술 (`도입이 격차 요인으로 부상`)도
허용. 핵심은 standalone meaningfulness이지 종결 어미 형태가 아님.

수치가 핵심인 슬라이드는 명사구가 자연스럽고, 변화·부상이 핵심인 슬라이드는
짧은 서술이 자연스럽다.

## 4가지 self-review 검증 질문

LLM self-review 단계에서 헤드 하나마다 다음 4개를 차례로 묻는다.

1. **반문 테스트** — 헤드만 떼어서 보여줬을 때 "왜?" "그래서?" 반문이 드는가?
2. **요소 테스트** — 주체+사실+함의 중 최소 두 가지가 있는가?
3. **이동성 테스트** — 헤드를 다른 슬라이드로 옮겨도 자연스러운가? (자연스러우면 너무 일반적 = 약함)
4. **deck arc 테스트** — 청중이 deck 헤드만 훑었을 때 deck 전체 thesis를 짐작할 수 있는가?

4개 중 1개라도 실패하면 헤드 재작성.

## 좋은 예 / 나쁜 예 매핑

| ❌ 나쁜 예 | 문제 | ✅ 교정 |
|---|---|---|
| AI의 영향 | 라벨, 함의 누락 | AI가 일하는 방식과 일자리 구성을 재편 |
| 기업 도입률 | 라벨 | Fortune 500의 92%가 이미 생성형 AI 도입 |
| ChatGPT 1억 사용자 달성 사례 | "그래서 뭐?" 반문 | ChatGPT, 2개월 만에 1억 사용자 — 역대 최단 채택 |
| AI는 어떻게 변화시키는가 | 의문형 | AI가 일상의 검색·작성·요약을 분 단위로 단축 |
| 직무와 산업의 재편 | 다중 주제·라벨 | 노동 30%가 AI 대체 가능 — 핵심은 '재구성' |
| 우리가 어떻게 대처해야 할 수 있을지 | 의문형·막연 | AI 활용 능력이 신입 채용 차별 요인으로 부상 |
| 법률 분야의 AI 변화 | 변화 방향 누락 | 법률·의료가 정형 업무 자동화 1순위 |
| AI 격차와 전망 | "전망"이 무엇인지 모름 | AI 격차가 기업 경쟁력 1차 변수로 등장 |

공통 패턴: **[주체] + [강한 사실/수치] + [함의 한 조각]** 이 한 줄에 들어가면
standalone이 된다.

## 잘 쓰인 head_message 패턴

다음 패턴 중 하나에 fit하면 standalone일 가능성 높음:

| 패턴 | 예 |
|---|---|
| 주체 + 수치 + 시점/맥락 | ChatGPT, 2개월 만에 1억 사용자 — 역대 최단 |
| 주체 + 비율/규모 + 함의 | Fortune 500의 92%가 이미 도입 — 운영 단계로 이동 |
| 변화 + 영향 영역 | AI 격차가 신입 채용 차별 요인으로 부상 |
| 사실 + 시사점 | 노동 30% AI 대체 가능 — 핵심은 '재구성' |
| 비교 + 결론 | Threads 5일·TikTok 9개월 vs ChatGPT 60일 — 카테고리 outlier |
| 영역 + 1순위/특이점 | 법률·의료가 정형 업무 자동화 1순위 |

## key_takeaway와의 분업

`head_message`와 `key_takeaway`는 의미층이 다르다:

| 필드 | 무엇을 담나 | 예 |
|---|---|---|
| head_message | 슬라이드 위 헤더에 표시되는 **사실·결론** | "Fortune 500의 92%가 이미 생성형 AI 도입" |
| key_takeaway | 청중이 가져갈 **insight·행동** | "도입은 끝났다 — 이제 운영 격차가 경쟁력" |

deterministic check가 둘의 jaccard overlap > 70%면 reject. 같은 말 반복 금지.

## 마지막 — 작성자 점검

LLM이 헤드를 출력하기 전 머릿속으로 다음 한 줄을 떠올려야 한다:

> "이 헤드만 보여줘도 청중이 이 슬라이드의 결론을 알 수 있을까?"

답이 *예*면 좋은 헤드. *아니오*면 [주체]·[사실]·[함의] 중 누락분을 채워 다시.
